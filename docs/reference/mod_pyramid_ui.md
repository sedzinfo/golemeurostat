# Pyramid module - UI

A country to pick, and its population pyramid, animated by year, as in
golemworldbank.

## Usage

``` r
mod_pyramid_ui(id)
```

## Arguments

- id:

  Character. Module namespace id.

## Value

A `tagList` of Shiny UI elements.

## Examples

``` r
if (FALSE) { # \dontrun{
shiny::fluidPage(golemeurostat:::mod_pyramid_ui("pyramid"))
} # }
```
