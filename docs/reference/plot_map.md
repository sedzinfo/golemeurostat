# Map of the countries, animated by year

The countries of
[`countries()`](https://sedzinfo.github.io/golemeurostat/reference/countries.md)
colored by the value of the indicator, from light for low to dark blue
for high, on one scale for all the years.

## Usage

``` r
plot_map(data, indicator)
```

## Arguments

- data:

  Data frame from
  [`get_indicator()`](https://sedzinfo.github.io/golemeurostat/reference/get_indicator.md).

- indicator:

  The `id` of the indicator in
  [`indicators()`](https://sedzinfo.github.io/golemeurostat/reference/indicators.md),
  for the title and the unit.

## Value

A plotly object.
