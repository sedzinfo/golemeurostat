# Regions module - UI

A regional indicator to pick, across the page, and a map of the regions
of Europe colored by it, animated by year, as the map of the countries.

## Usage

``` r
mod_regions_ui(id)
```

## Arguments

- id:

  Character. Module namespace id.

## Value

A `tagList` of Shiny UI elements.

## Examples

``` r
if (FALSE) { # \dontrun{
shiny::fluidPage(golemeurostat:::mod_regions_ui("regions"))
} # }
```
